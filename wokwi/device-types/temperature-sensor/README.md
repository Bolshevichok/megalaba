# Датчик температуры

Тип устройства: `temperature-sensor`

## Описание
Измеряет температуру воздуха в теплице.

## Пины
| Компонент | Пин |
|-----------|-----|
| DHT22     | 15  |

## MQTT топики

### Публикуемые
- `devices/{id}/sensors/temperature` — значение температуры (°C)

### Пример сообщения
```json
{"value": 24.50}
```

## Сборка
```bash
pio run -e temperature-sensor
```

## Wokwi
Откройте `diagram.json` в Wokwi для симуляции.
