# Датчик освещённости

Тип устройства: `light-sensor`

## Описание
Измеряет уровень освещённости в теплице.

## Пины
| Компонент | Пин |
|-----------|-----|
| LDR       | 34  |

## MQTT топики

### Публикуемые
- `devices/{id}/sensors/light` — значение освещённости (lux, 0-1000)

## Пример сообщения
```json
{"value": 450}
```

## Сборка
```bash
pio run -e light-sensor
```

## Wokwi
Откройте `diagram.json` в Wokwi для симуляции.
