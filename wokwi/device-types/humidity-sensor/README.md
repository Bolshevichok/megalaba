# Датчик влажности

Тип устройства: `humidity-sensor`

## Описание
Измеряет влажность воздуха в теплице.

## Пины
| Компонент | Пин |
|-----------|-----|
| DHT22     | 15  |

## MQTT топики

### Публикуемые
- `devices/{id}/sensors/humidity` — значение влажности (%)

## Пример сообщения
```json
{"value": 65.00}
```

## Сборка
```bash
pio run -e humidity-sensor
```

## Wokwi
Откройте `diagram.json` в Wokwi для симуляции.
